🧭 Escolhas do projeto

🔍

Ler cookies

Leitura feita com document.cookie (singular), que devolve todos os cookies do site.

💾

Gravar tema

Gravação com max-age=3600, path=/ e SameSite=Lax.

🗑️

Apagar tema

Remoção com max-age=0 e path=/ — o navegador descarta na hora.

🆔

IDs do HTML

O getElementById usa exatamente o id do input (tema), sem erro.

📄

Entrega

Projeto em arquivo único HTML + CSS + JS, pronto para abrir no Live Server.

🔒

Segurança

Cookies com SameSite=Lax, a boa prática moderna para privacidade.
